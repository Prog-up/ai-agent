# Gemma 4 SSH MCP Chatbot

Interactive chatbot using Gemma 4 and SSH MCP transport.

## Files

- **[gemma4.py](./gemma4.py)**: Gemma 4 model loading and inference logic.
- **[main.py](./main.py)**: Main entry point for the chatbot with SSH MCP client.

## Usage

Ensure you have the SSH MCP server running on the target machine.
Update the connection details in `main.py`.
