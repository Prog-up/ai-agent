# AI Agent Research

This repository contains various research experiments and benchmarks for building AI Agents using OpenVINO and MCP.

## Research Branches

- **[feature/benchmarks](https://github.com/Prog-up/ai-agent/tree/feature/benchmarks)**: LLM inference benchmarks (Local vs OpenAI, OpenVINO vs llama.cpp).
- **[feature/deepseek](https://github.com/Prog-up/ai-agent/tree/feature/deepseek)**: DeepSeek-V2-Lite OpenVINO INT4 conversion and performance.
- **[feature/gemma-docker-gateway](https://github.com/Prog-up/ai-agent/tree/feature/gemma-docker-gateway)**: Gemma 4 integration with Docker MCP Gateway.
- **[feature/gemma-fastapi-bridge](https://github.com/Prog-up/ai-agent/tree/feature/gemma-fastapi-bridge)**: Custom FastAPI bridge for Gemma 4 (VLM support).
- **[feature/gemma-mcp-ssh](https://github.com/Prog-up/ai-agent/tree/feature/gemma-mcp-ssh)**: Gemma 4 interactive chatbot via SSH MCP.
- **[feature/ovms-agentic-workflow](https://github.com/Prog-up/ai-agent/tree/feature/ovms-agentic-workflow)**: Agentic workflows using OpenAI Agents SDK and OVMS.
- **[feature/mcp-client-docs](https://github.com/Prog-up/ai-agent/tree/feature/mcp-client-docs)**: MCP client snippets and documentation.

## Setup

Use `uv` to manage dependencies. Consolidated dependencies can be found in `pyproject.toml`.
