# MCP Client Snippets and Docs

Collection of Python MCP client snippets, transport examples, and notebook utilities.

## Files

- **[stdio_client.py](./stdio_client.py)**: Example of an MCP client using Stdio transport.
- **[cmd_helper.py](./cmd_helper.py)**: Helper for running commands.
- **[notebook_utils.py](./notebook_utils.py)**: Utilities for using MCP in Jupyter notebooks.
- **[gemma4.ipynb](./gemma4.ipynb)**: Notebook demonstrating Gemma 4 with MCP.
- **[optimum.py](./optimum.py)**: Optimum-intel related helper.
